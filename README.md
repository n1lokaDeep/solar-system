# Солнечная система

Интерактивная 3D-модель Солнечной системы в браузере. Восемь планет, Солнце, семнадцать крупных спутников и два пояса малых тел — всё на реальных текстурах NASA, с орбитальным движением и карточками объектов.

Открывается как обычная страница, ничего собирать и ставить не нужно.

## Как запустить

Из-за того, что код разбит на ES-модули и подгружает текстуры, открывать файл напрямую (`file://`) нельзя — браузер заблокирует загрузку. Нужен любой локальный сервер:

```
python -m http.server 8777
```

и затем открыть http://127.0.0.1:8777/

Подойдёт любой другой статический сервер (`npx serve`, Live Server в VS Code и т.д.) — требования только к отдаче статики.

## Что внутри

**Планеты.** Восемь планет с реальными картами NASA. У Земли отдельными слоями идут облака (медленно дрейфуют) и ночные огни городов, которые загораются только на теневой стороне. У Венеры — слой облачности поверх поверхности.

**Солнце.** Шейдер с анимацией фотосферы, затемнением лимба и хромосферной кромкой, плюс трёхслойная корона.

**Спутники.** Луна, Фобос и Деймос, галилеевы спутники Юпитера, Титан с Энцеладом, Реей и Япетом, спутники Урана и Тритон. У Луны настоящая текстура NASA, у остальных — процедурные, но с корректной для каждого тела палитрой: вулканическая жёлтая у Ио, белый лёд с трещинами у Европы, оранжевая дымка у Титана.

**Пояса.** Главный пояс астероидов между Марсом и Юпитером (6500 тел, настоящая геометрия с вращением) и пояс Койпера от 30 до 50 а.е. (9000 ледяных тел).

**Кольца.** У Сатурна, Юпитера, Урана и Нептуна. У Сатурна процедурная текстура с делениями Кассини и Энке и аналитическая тень от планеты на кольцах — считается в шейдере по положению Солнца.

## Технические детали

Написано на Three.js (лежит локально в `lib/`, внешние CDN не нужны). Сборщика нет — нативные ES-модули.

**Масштабы.** Расстояния честные: одна единица сцены равна миллиону километров. А вот радиусы планет так не отобразить — Земля была бы точкой в 0,00004 юнита, поэтому они сжаты степенной функцией (показатель 0,42). Пропорции между планетами при этом сохраняются: Юпитер остаётся в разы крупнее Земли, Меркурий — мельче. Орбиты спутников тоже схематичны, иначе Луна оказалась бы внутри Земли.

**Тени колец** считаются без shadow map: для каждой точки кольца проверяется расстояние до оси «Солнце — центр планеты». Если оно меньше радиуса планеты, точка в тени. Дёшево и работает на любом железе.

**Освещение** — точечный источник в центре с нулевым затуханием, чтобы далёкие планеты получали столько же света, сколько ближние.

## Структура

```
index.html      разметка и подключение модулей
style.css       оформление интерфейса
app.js          связка: состояние, ввод, цикл отрисовки
scene.js        сборка сцены, шейдеры, спутники, пояса
camera.js       камера: облёт, перелёты, слежение за объектом
card.js         карточка объекта с мини-рендером шара
data.js         данные планет
bodies.js       данные спутников и поясов
textures.js     загрузка карт NASA и процедурные текстуры
tex/            текстуры
lib/            Three.js
```

## Текстуры

Карты планет, Солнца и Луны взяты с [solarsystemscope.com](https://www.solarsystemscope.com/textures/) — это свободные для использования текстуры на основе данных NASA.

Панорама звёздного неба (8K) оттуда же. Оригинал был очень тёмным и после тональной компрессии Млечный Путь не читался, поэтому яркость выровнена заранее, а поверх добавлен слой из 5200 звёзд, которые рисуются шейдером с постоянным размером в пикселях — иначе они мылятся при растягивании панорамы на сферу.
